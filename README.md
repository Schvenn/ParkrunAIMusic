# Free Parkun MP3 songs
All of these MP3's have been made via the songer[.]co AI service.
The lyrics are my own and you are free to use them in your videos.
Cut them, splice them, loop them, speed them up, slow them down.
I don't care.
They are intended to help Parkrun directors increase engagement on social media by allowing them to create custom videos.
Use these with the [NewPhotoReel](https://github.com/Schvenn/NewPhotoReel) PowerShell script I created and you can create professional looking and sounding videos with very little effort.
